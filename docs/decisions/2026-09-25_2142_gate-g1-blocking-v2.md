# Decision: gate-g1-blocking-v2

- **Date (IST):** 2026-09-25 21:42
- **Author:** ameya
- **Status:** accepted
- **Affects:** block (`src/ber/block/index.py`, `src/ber/block/__init__.py`; params `nw_words`, `ns_domain_len`)

## Context

Blocking v1 (`ameya-block-v1`) missed 27.1k holdout true pairs (pair recall 0.9857). 17.9k of them have a record address, which puts +0.0032 macro F0.5 within reach if they were candidates and predicted. The analysis in `experiments/ameya/model-v1/ANALYSIS_v2.md` found two causes:

- **Typo'd or shortened names on a number-less street**, e.g. "Dynamic Nnsaq P.C. | DURHAM DR, ANDOVER, MA" or "Federal LLC Services".
  - The search seeds candidates from the query's rare tokens, which here are only the typos, so the true S1 is never seeded.
  - (name token × address word) compounds are shared by 38% of these misses, and by 97% of the Indic-script ones.
- **Domains and handles** ("renterianaborweddle.com", "@eastcomplete", "ewinnovations.com").
  - The joined name only prefix-matches the S1's joined name.
  - Address-only matches with short S1 addresses outrank the true S1.

## Options considered

1. Keep v1.
2. **v2 = v1 + two additions**, with the same trims (trim_s1=15, trim_r=4, ns_ngrams=4, Indic dictionary ameya-fx1):
   - `nw_words=6`: kind-0 compounds (one of the first 2 name tokens × one of the first 6 address words of 4+ letters that are not street types);
   - `ns_domain_len=8`: records whose name is one token of 8+ letters join the name-only view (character 4-grams).
3. Prefix keys of the joined name. Not taken: the shared 7-letter prefixes are common (median 885 S1 per key), so they would not seed.

## Decision

**Option 2.** Holdout (`python -m ber.pipeline --stage evaluate --split train --tag ameya-block-v2`):

| | v1 | **v2** |
|---|---|---|
| pair recall | 0.9857 | **0.9899** |
| India / US | 0.9836 / 0.9872 | 0.9875 / 0.9916 |
| S2 / S3 | 0.9877 / 0.9839 | 0.9914 / 0.9885 |
| oracle F0.5 | 0.9956 | **0.9970** |
| candidates per S1 (mean / p99) | 29.5 / 119 | 30.3 / 103 |
| train pairs | 65.2M | 66.8M |
| keys per record, train runtime | 21.9, 13 min | 28.6, 13 min |

- Recall gains +0.42 pt for +2.5% pairs, and it is at the G1 v0 bar (99.0%).
- The remaining misses are mostly records with an empty address and a shared name, where no key can find the owner, and brand names at an address with a different house number.

Command:
```
python -m ber.pipeline --stage block --split train --tag ameya-block-v2 --set trim_s1=15 --set trim_r=4 --set indic_dict=ameya-fx1 --set ns_ngrams=4 --set ns_domain_len=8 --set nw_words=6 --set dev_tag=ameya-block-v2-dev
```

## Consequences (what changes, what we give up, how we'll know it was right)

- Features v3, stages 1–2 and the decision are rebuilt on `ameya-block-v2`: tags `ameya-fx3`, `ameya-s1-v3`, `ameya-s2-v3`, `ameya-model-v3`.
- The end-to-end check is model v3 vs model v2lg on the holdout.
