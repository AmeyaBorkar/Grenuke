# Decision: gate-g4-stage2

- **Date (IST):** 2026-09-25 21:03
- **Author:** sachi
- **Status:** accepted
- **Affects:** stage 2 (collective model) in the model path

## Context

FINAL_PLAN §9, gate G4: does the stage-2 collective model beat stage 1 alone?
Same 79 features (`ameya-fx2-dev`), dev fold 0, 27,651 S1; paired bootstrap (`ber.eval.paired_bootstrap`, 1,000 resamples).
Baseline: stage-1 XGBoost only (`sachi-s1-fx2-dev`), threshold 0.68. Candidate: model v2 stage 2 (`ameya-s2-v2-dev` pc), threshold 0.67.

## Options considered

1. Stage 1 only: macro F0.5 0.97745.
2. Stage 1 + stage 2: macro F0.5 0.98438.

## Decision

Keep stage 2. Delta +0.00692, CI [+0.00622, +0.00772], p_better 1.000, n 27,651 (bar: +0.002 with CI > 0).
Stage 2 lifts singleton F0.5 0.968 -> 0.985 and recall 0.949 -> 0.963.

## Consequences (what changes, what we give up, how we'll know it was right)

- Of v2's gain over v0 (0.9652 -> 0.9844), about two-thirds comes from the 79 features and one-third from stage 2.
- Error analysis (`experiments/sachi/error_analysis_v2.py`): the remaining loss is mainly recall on records with an
  empty address (61% of below-threshold misses, 98% of records taken by another S1).
- Re-check on the full holdout at the integration run.
