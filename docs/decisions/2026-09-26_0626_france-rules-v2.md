# Decision: france-rules-v2

- **Date (IST):** 2026-09-26 06:26
- **Author:** ameya
- **Status:** proposed. The rules are validated on the US/India holdout labels; their France value needs the leaderboard (`2026-09-26-v5all-ops2-c2` vs `2026-09-26-v5all-ops-c2`, both packaged). Extends `2026-09-26_0417_france-generator-ops-and-final-fit.md`.
- **Affects:** `experiments/ameya/model-v1/post_ops.py` (applies only to countries without training labels, i.e. France), the submission

## Context

The France research thread (`RESEARCH_v5.md` §6) found patterns left after the first rules:
- a. look-alike swaps whose record street has a typo;
- b. list-word appends with nothing dropped;
- c. acronyms at the same address;
- d. house-number edits;
- e. short-code typos.

`post_ops.py --measure` runs the same classification code on the US/India holdout and prints each population's truth rate and the model's acceptance.

## Options considered

| population (at the S1's address) | US truth / predicted | India truth / predicted | verdict |
|---|---|---|---|
| B look-alike swap, incl. street typo (a) | 3.1% (typo 5.1%) / 3.1% | 0.6% (typo 0%) / 0.5% | drop |
| A drop + list append, incl. street typo | 99.7% (typo 99.8%) | 98.3% (typo 97.1%) | add |
| APP list append, nothing dropped (b) | 98.9% / 99.0% | 99.6% / 99.6% | add |
| ACR acronym (c) | 99.9% / 98.0% | 99.8% / 98.4% | add |
| NUM −1/−2 (d) | 97.6% / 88.5% | 78.2% / 76.9% | no: the model's rejections are right in India and France's rate is unknown; adding pays only above 75% precision |
| NUM one digit substituted / inserted-deleted (d) | 91.0% / 95.0% | 70.9% / 90.4% | no (same reason); the model learns it via `feats_nx.py` |
| CODE short-code typo (e) | 42.6% | 44.0% | no |

## Decision

`post_ops.py` rules B, A, APP, ACR (default `--rules B,A,APP,ACR`) for countries without training labels. Adds must meet all of:
- the pair is in the candidate set;
- the S1 is the record's best-scoring S1;
- the record is not predicted elsewhere.

On `ameya-model-v5all-c2` in France:
- 19,503 look-alike predictions dropped (first rules: 18,406);
- added: A 7,227 (was 6,086), APP 3,877, ACR 853;
- 1,562 adds fall outside the candidate set and are not made.

Package: `submissions/files/2026-09-26-v5all-ops2-c2/` (validator PASS; matching sha256 `76fe7eff4bb37e9eab392b25d4cb0e563a91f0953131bc9b908909ca44fa3d4b`, candidates `a27e8679…` as `-c2`).

## Consequences (what changes, what we give up, how we'll know it was right)

- Expected about +0.002 France F0.5 (+0.0003 LB) over the first rules, if France follows the US/India truth rates as it did for the first rules.
- US/India predictions are untouched.
- **Right if** `v5all-ops2-c2` ≥ `v5all-ops-c2` on the leaderboard (the difference is France only).
- **Wrong if** it loses. Then APP/ACR are not true copies in France; revert to `--rules B,A`.
